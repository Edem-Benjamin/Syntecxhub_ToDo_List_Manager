Syntecxhub To-Do List Manager

A Python-based task management project developed as part of the Syntecxhub AI Internship Program.

Overview

The Syntecxhub To-Do List Manager is a simple application designed to help users manage tasks using Python. The project uses a JSON file to store task data.

Features

- Task management using Python
- JSON-based task data storage
- Persistent task data through "tasks.json"

Technologies Used

- Python — application logic
- JSON — task data storage

Project Structure

Syntecxhub_ToDo_List_Manager/
├── todo.py
├── tasks.json
└── README.md

How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal in the project folder.
5. Run:

python todo.py

If your system uses the "python3" command, run:

python3 todo.py

Learning Objectives

This project provides practical experience with Python programming, working with JSON data, and organizing a small application.
